How a value is made

implied = exp(a + b · ln TVL) × growth × age

A protocol is listed as records no token when its DefiLlama record carries no market cap, no CoinGecko id and no symbol. That is the record’s word, never proof it has none: a protocol on this board may still have a token its record does not carry. Values are this radar’s claim, not a prediction that a token is issued, or when.
